# Pasta de Evidências

Coloque aqui **prints, fotos e arquivos** que comprovam o desenvolvimento e os testes do sistema.

---

## O que colocar aqui

Adicione as evidências conforme for realizando as etapas:

### 1. Prints das telas funcionando
- tela-inicial.png
- tela-produtos.png
- tela-carrinho.png
- tela-finalizar.png
- tela-pedido-sucesso.png
- tela-acompanhar.png
- admin-produtos.png
- admin-pedidos.png
- responsivo-celular.png (print ou foto do celular)

### 2. Testes automatizados
- testes-automatizados.png (print do terminal rodando os 4 testes)

### 3. Testes com os 5 colegas
- Prints ou arquivos relacionados a cada teste realizado

### 4. Erros encontrados (se houver)
- Para cada erro do laudo, coloque um print com nome correspondente:
  - erro-01.png, erro-02.png, ...

### 5. Correções
- Para cada correção: print ANTES e DEPOIS
  - correcao-01-antes.png / correcao-01-depois.png

---

## Dicas

- Salve os arquivos com **nome descritivo** (evite `imagem1.png`, `print.png`)
- Prefira PNG para prints (melhor qualidade)
- Se precisar, crie subpastas para organizar: `screenshots/`, `testes-colegas/`, `erros/`, etc.
- No laudo de qualidade, faça referência ao nome do arquivo de evidência
