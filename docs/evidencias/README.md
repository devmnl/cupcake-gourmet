## O que será armazenado nesta pasta

- `tela-carrinho.png` — Carrinho com itens e total calculado
- `tela-finalizar.png` — Formulário preenchido
- `tela-sucesso-pedido.png` — Tela de sucesso com nº do pedido

- `tela-admin-pedidos.png` — Lista de pedidos
- `tela-admin-detalhes.png` — Modal de detalhes do pedido
- `tela-mobile.png` — Responsividade no celular

- `testes-automatizados-execucao.png` — Terminal mostrando os 10 testes passando
- `testes-automatizados-log.txt` — Saída completa do script

### 3. Evidências dos Testes com 5 Colegas

### 5. Evidências de Correções
- `correcao-erro-01-antes.png` + `correcao-erro-01-depois.png`
- etc.

### 6. Banco de Dados (opcional: cópia para histórico)

---

## Como Adicionar

Quando realizar testes e gerar evidências:
1. Salve cada arquivo com **nome descritivo** (não use `imagem1.png`, `print.png` etc.)
2. Prefira formatos **PNG** para prints (qualidade + transparência)
3. Atualize este README marcando os itens coletados
4. No Laudo de Qualidade, faça referência ao nome do arquivo de evidência correspondente
