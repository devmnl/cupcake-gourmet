# Testes com Usuários - Cupcake Gourmet

> **IMPORTANTE:** Este arquivo contém o TEMPLATE preparado para os 5 testes com colegas.
> Os campos em branco serão preenchidos APÓS os testes reais serem realizados.
> **Não inventar** nomes, datas ou resultados.

---

## Planejamento dos Testes

**Quantidade de participantes:** 5 colegas  
**Perfil:** Estudantes (usuários finais representativos)  
**Ambiente de teste:** Navegador web moderno (Chrome, Edge ou Firefox) com acesso ao sistema rodando localmente  
**Cenário guia:** Cada colega recebe o seguinte roteiro para executar:
1. Abrir a página inicial e navegar até os produtos
2. Visualizar os cupcakes e adicionar 3 unidades de um produto e 2 de outro
3. Acessar o carrinho, diminuir 1 quantidade e remover 1 item
4. Verificar o total, depois finalizar o pedido preenchendo dados
5. Anotar o número do pedido gerado
6. Consultar o status do pedido na tela de acompanhamento
7. Acessar a área administrativa, cadastrar um produto teste
8. Editar o produto teste, depois excluí-lo
9. Na aba Pedidos da área admin, visualizar detalhes e alterar status
